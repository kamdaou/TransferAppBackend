# TransferApp API Documentation

## Swagger UI (Interactive)

With the app running, open in your browser:

```
http://localhost:8080/swagger-ui/index.html
```

This gives you an interactive UI where you can test endpoints directly. To authenticate:
1. Login via `POST /api/auth/login` to get a JWT token
2. Click the "Authorize" button (lock icon) at the top
3. Enter: `Bearer <your-token>`
4. All subsequent requests will include the token

## OpenAPI JSON (for Postman / code generation)

### Import into Postman

1. With the app running, download the spec:
   ```
   http://localhost:8080/v3/api-docs
   ```
2. In Postman: **Import** > **Link** > paste the URL above > **Import**
3. This creates a full collection with all endpoints, request bodies, and schemas

### Import as file

1. Save the spec to a file:
   ```bash
   curl http://localhost:8080/v3/api-docs -o transferapp-api.json
   ```
2. In Postman: **Import** > **File** > select `transferapp-api.json`

### YAML format

```
http://localhost:8080/v3/api-docs.yaml
```

## For Android Developers

Give Android devs either:
- The Swagger UI URL (if they have access to the running server)
- The exported `transferapp-api.json` file (they can import into Postman or any OpenAPI-compatible tool)
- The YAML spec for code generation with OpenAPI Generator:
  ```bash
  curl http://localhost:8080/v3/api-docs.yaml -o transferapp-api.yaml
  ```

## Notes

- The API docs are auto-generated by **springdoc-openapi** from the controller annotations
- Docs are available without authentication (public endpoints)
- Any changes to controllers/DTOs are automatically reflected in the docs after restart
